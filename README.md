# fantui

图像反推 / 标签扩写 / H3 视频提示词前端（Next.js 14 + Tailwind + framer-motion）。

## 功能标签页
- 图像反推：批量上传图片，反推出图提示词。
- 标签扩写：从关键词扩写为完整描述，支持剧场模式分幕。
- H3 视频：上传参考图 / 参考音频 + 剧情描述，生成 MiniMax H3 结构化视频提示词（时长 2~20 秒）。
- 词记录：登录后自动留档反推 / 扩写 / 剧场 / H3 的全部结果（含当时上传的图片），按账号隔离，保留 24 小时。

## 账号与词记录
- 右上角「登录」可注册 / 登录，token 存在 `localStorage`，30 天有效。
- 登录后所有生成结果自动写入当前账号的词记录；未登录仍可正常使用，只是不留档。
- 词记录页支持按类型筛选、展开全文、复制、单条删除与清空；超过 24 小时的记录由后端自动清除。
- 反推和 H3 的记录会带上当时上传的图：卡片上显示缩略图条，展开后是完整图墙，点击任意图可看大图。
- 全站按移动端优先适配：导航、Tab、上传区、配置抽屉、登录弹窗与词记录卡片在窄屏下均可完整显示。

## 自定义 API
- 配置面板里填自己的密钥 / 接口地址后，点模型旁的刷新按钮会直接向你的接口 `GET /models` 拉取模型列表。
- 接口地址可只填域名（自动补 `/v1`）；结尾加 `#` 表示按原样使用该地址。
- 拉不到列表时会提示原因，并可切换为手动填写模型名。

## H3 视频提示词
调用后端 `POST /api/h3/video` 与 `GET /api/h3/modes`（后端仓库 DaBiao 已内置 `h3-prompt-writing` skill）。
- 模式：Ref2VA（参考图生视频，默认）、I2VA、FL2VA、L2VA、T2VA。
- Ref2VA 将上传的每张图按阅读顺序映射为 `<Picture N>`、每条音频映射为 `<Audio N>`，输出六段：
  `subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music`。
- 参考音频可多条，每条选择引用角色（音色 / 台词复用 / 配乐风格 / 配乐直接复用 / 环境声 / 音效 / 节奏 / 整轨复用）并可加备注。
  选到支持音频的模型（Gemini、带 `audio`/`omni` 的模型）时音频会真的送进模型，否则只按角色写进提示词，界面会提示当前状态。

## 开发
- `.env` 设置 `NEXT_PUBLIC_API_URL` 指向后端地址。
- `npm install && npm run dev`（构建 `npm run build`）。
